# Tausif Islam Sheik - Personal Portfolio

A modern, responsive single-page portfolio built with Next.js, TypeScript, GSAP, Framer Motion, and Lenis smooth scrolling.

## Features

- **Responsive Navigation** - Fully responsive navbar with mobile menu
- **Animated Hero Section** - Text reveal animations and gradient effects
- **About Section** - Personal introduction with interests
- **Skills Section** - Categorized skill tabs with 50+ technologies
- **Projects Section** - 4 featured projects with detailed modals
- **Contact Section** - Contact form and information
- **Smooth Scrolling** - Lenis-powered smooth scroll experience
- **Dark Theme** - Modern dark UI with purple/pink gradients
- **Animations** - GSAP and Framer Motion animations throughout

## Tech Stack

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Framer Motion
- **Smooth Scroll**: Lenis (@studio-freight/lenis)
- **Icons**: Lucide React
